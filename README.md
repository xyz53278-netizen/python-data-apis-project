# 📊 Python Data & APIs — Data Analysis Application

A beginner-friendly Python project focused on data analysis, data cleaning, visualization, REST API integration, and automated report generation.

## 🚀 Project Overview

This project demonstrates how Python libraries can transform raw datasets into meaningful insights. It loads CSV data, handles missing values, performs statistical analysis, generates visualizations, consumes REST APIs, and saves an analysis report.

## ✨ Features

- 🔢 **NumPy:** Numerical calculations and array operations
- 🐼 **Pandas:** DataFrames, data manipulation, and cleaning
- 🧹 **Data Cleaning:** Handle missing values and remove duplicate rows
- 📈 **Data Visualization:** Generate charts using Matplotlib and Seaborn
- 🌐 **REST API Integration:** Fetch data using HTTP requests
- 🔄 **JSON Processing:** Parse and save API responses
- 📝 **Automated Reporting:** Generate reports and export cleaned datasets
- 🛡️ **Error Handling:** Handle invalid files and API request failures

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd python-data-apis-project
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual repository URL.

**2. Create a virtual environment**

```bash
python -m venv .venv
```

**3. Activate the environment**

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

**4. Install dependencies**

```bash
python -m pip install -r requirements.txt
```

**5. Run the application**

```bash
python main.py
```

## 📊 Generated Outputs

After running the application, check these files and folders:

- `reports/analysis_report.txt` — data analysis report
- `reports/cleaned_dataset.csv` — cleaned dataset
- `reports/api_users.json` — optional API response
- `plots/` — generated charts and visualizations

The API feature requires an internet connection.
